# macdowsOS WindowChanger v32

默认开启“自动接管所有支持窗口”。**不设软件黑白名单，不按软件名称、进程名或是否单独测试过来放行。** 检测到受支持且尚未接管的窗口就立即尝试注入，包含启动前已打开、后来新出现和恢复显示的窗口。

没有逐窗口排除表。手动“还原选中”或“全部还原”会暂停整个自动接管开关；重新开启后，对所有支持窗口再次尝试。明确保存过的暂停选择仍会保留，不偷偷覆盖。

初始化固定等待已去掉。为了不堵塞界面，接管分批执行但立即续批；临时失败仅做有上限的退避重试，不形成永久黑名单。隐藏/最小化窗口暂不改写不可用的几何，显示后再尝试。

“支持”仍由实际后端能力、运行时 ABI 和原控件布局检查决定，不代表只看框架名字就跳过安全校验。未支持版本/不匹配布局不会强制写入，也不使用覆盖窗口或未知框架原生兜底；详见 `original-frameworks.md`。

## 使用

解压后，以管理员身份运行根目录 `WindowStyler.exe`，保留旁边的 `x86` 目录。关闭主窗口会驻留托盘，托盘提供打开、自动接管、开机自启、暂停并还原及还原退出。

勾选“开机自启”才创建当前用户的最高权限交互登录任务，后台启动、不保存密码；取消则删除本程序自己的任务。启动设置不会因版本升级被擅自开启。

包中包含 x64/x86 所需 VC++ 可再发行运行库。源码和 GPLv3 授权见随包说明及 [GitHub 仓库](https://github.com/aiboqiao6/macdowsOS-WindowChanger)。MinHook 授权见 `third_party/minhook-LICENSE.txt`。

回归使用随机生成的新窗口类和新软件名称，没有 Sample 测试标记，验证不会因为缺少测试记录而跳过接管。没有使用 computer use，也没有为了更新而关闭用户运行中的旧版本。
