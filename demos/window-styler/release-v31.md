# macdowsOS WindowChanger

以管理员身份启动 `WindowStyler.exe`。完整包包含 x64 主程序及 `x86` 辅助目录，请勿拆散或只复制单个 EXE。

## 日常使用

- 自动接管默认开启，只处理通过框架/ABI/原布局校验的窗口；暂时未准备好的窗口延后重试，最小化窗口等还原后再接管。
- 手动“还原选中”后，该窗口不被自动立即接管。“全部还原”同时暂停自动接管；重新勾选自动接管可恢复。
- 关闭主窗口或最小化会驻留托盘，不中断已接管窗口。托盘可打开界面、切换自动接管/自启、全部还原或“还原并退出”。
- 双击或键盘选择托盘图标可打开主界面。再次启动程序只打开已有实例；Explorer 任务栏重建后重新注册图标。
- 勾选“开机自启”后，为当前用户创建登录计划任务，以最高权限在交互会话后台启动，不保存密码，也不会在每次登录时要求一次新的 UAC 点击。首次配置仍需要管理员权限。
- 取消“开机自启”删除本程序自己的任务。移动程序目录后，请在新位置重新启用以更新任务路径。
- 自动接管偏好按用户保存。开机自启默认不替用户开启；勾选后才修改系统配置。

不适配的窗口会显示原因，不会用额外覆盖窗口或未知框架的原生标题栏兜底。具体 ABI、Office 起始页等限制见[适配范围](original-frameworks.md)。关闭/托盘策略沿用目标应用原按钮逻辑；自动测试不点击用户应用的关闭按钮。

## 验证范围

本轮对自有窗口验证托盘注册/唤回、单实例、关闭驻留、任务栏重建恢复、原生窗口自动接管/最小化延后/手动排除、暂停持久化、退出与崩溃恢复。临时计划任务由任务计划程序实际执行，检查当前用户 SID、登录触发器、交互令牌、最高权限与后台参数；同名非本程序任务拒绝覆盖或删除。测试后删除临时任务和设置，保留用户真实配置。

没有注销、重启 Windows 或使用 computer use；登录自启的证据是任务配置回读与任务计划程序实际启动，不声称做过真实重启登录测试。测试工具、原生样例及历史截图不进入日常运行包。

包内自带匹配架构的 VC++ 可再发行 DLL。框架后端依赖的目标运行时由对应目标应用自身提供，不将 Office、Qt 或 Windows 框架私有 DLL 打包分发。
