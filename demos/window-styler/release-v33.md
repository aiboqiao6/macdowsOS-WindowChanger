# macdowsOS WindowChanger v33

默认接管所有检测为支持的窗口，不设软件黑白名单，也不按是否单独测试过筛选。解压后以管理员身份运行 `WindowStyler.exe`，保留旁边的 `x86` 目录。关闭主界面后驻留托盘；开机自启需在界面或托盘主动开启。

本轮补充原标题按钮的隐藏、输入禁用和撤销恢复，修正旧式 DPI 窗口的标题裁剪，并跟踪应用设置的标题背景色、文字色和深色模式。旧式 DPI 标题被其他窗口遮挡、无法可靠取得原配色时暂缓接管，窗口可见后再重试。

扩展 Electron 标题行避让，覆盖本轮验证的 VS Code、OpenCode 和 Trae 工作窗口；保留原主题背景，并验证按钮能力变化、标题树重建和导航撤销。支持范围取决于已验证的运行时与实际布局。原生同尺寸主题通知后的边框恢复也已修正。

新增 Avalonia 11.3.12 / FluentAvalonia 2.5 的 x64 原标题树后端，已验证 Watt Toolkit 当前深色窗口的附加、原按钮隐藏禁用、布局及撤销，位置和尺寸保持不变。亮暗切换、真鼠标操作、能力变化和异常恢复另在自有窗口通过；不代表 Watt 所有页面和主题均已验证。

XAML 合成窗口继续要求匹配的原树布局。仅凭非客户区几何选择 GDI 标题会出现接口几何不变、实际画面偏移的问题，因此 Picker 等未匹配布局保持原样，不能计为已适配。原生窗口仍按原标题按钮能力启用三灯，无系统菜单的窗口不获得关闭能力。

**本机所有已安装软件的适配尚未完成。** 软件库存和自有测试通过都不能代替实际软件的逐窗口验证。Office 的现有原树后端限已匹配的起始页；WinUI 3 后端仍限自有 fixture。微信内嵌 Qt 运行时缺少现有后端所需的公共入口，尚未适配。更多窗口、亮暗主题、不同 DPI 和未知版本仍有缺口，见源码中的 `verification-v33.md` 和 `original-frameworks.md`。

实际软件截图、窗口标题和本机安装路径只保存在本地 `out`，不包含在源码提交或运行包中。包中包含 x64/x86 的 VC++ 可再发行运行库，不包含测试程序。源码与 GPLv3 授权见 [GitHub 仓库](https://github.com/aiboqiao6/macdowsOS-WindowChanger) 及 `LICENSE.txt`，MinHook 授权见 `third_party/minhook-LICENSE.txt`。
